# Canonical AREA figures

These are the eight validated figures from the ROSMAP AREA analysis.

| Figure | Topic |
|---|---|
| 1 | Cross-phenotype recurrence |
| 2 | Cross-modal convergence |
| 3 | Signal architecture |
| 4 | Signal geometry and outliers |
| 5 | Covariate sensitivity |
| 6 | Cross-omic convergence |
| 7 | Biological programs and gene functions |
| 8 | Measured AD protein recovery |

Figures 1–7 are available as PDF, PNG and SVG.
Figure 8 is available as PDF and PNG.

The associated generating scripts are in `scripts/multiomic/`.
Methods and input provenance are documented in `docs/`.

These figures were generated from validated frozen intermediate inputs.
Some underlying data are not distributed publicly because access may
be governed by the source dataset's data-use terms.
